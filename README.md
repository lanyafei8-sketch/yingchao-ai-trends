# 映潮 AI 短片趋势榜

抖音与 B 站 AI 短片榜单原型。页面默认展示达到平台门槛的历史样本：抖音点赞不少于 10 万；B 站播放不少于 100 万或点赞不少于 5 万。2026-09-23 本轮公开检索没有发现可完整核验的近 48 小时达标作品，因此切换到“近 48 小时”会如实显示 0 条；默认“全部时间”视图展示 22 条历史达标作品，包括《槐灯》和《被裁掉的女孩》第一季纯享全集。

公开采样并非平台官方热搜或完整 TOP 30。抖音网页未展示可核实的播放量，因此该字段留空；没有同口径双快照时，增长速度也留空。《外星人要接我走》可确认点赞和分享较旧快照增长，但采样时刻不足以可靠换算每小时速度。两平台详情页显示的“万”是约数。详情中的热度解释属于创作推断，不是平台确认的流量原因；选题是新故事方向，避免照搬原作品。故事学习卡在证据不够时保留空缺；其中时间标注的分镜是**拟拍练习，不是原片逐秒实录**。

故事学习卡的内容保存在 `story-notes.js`。修改后执行 `node build-story-notes.js`，将内容合并到 `app.js`，使当前轻量预览服务能直接加载。

## 本地运行

安装 Node.js 后，在项目目录执行：

```bash
node server.js
```

浏览器打开 `http://localhost:4173`。也可以直接打开 `index.html`，但部分浏览器会限制本地文件下的数据接口请求。

## 3. 安装方法

项目只使用 Node.js 内置模块，没有第三方运行依赖，因此不需要执行 `npm install`。

1. 安装 Node.js，建议使用当前长期支持版本。
2. 克隆仓库并进入项目目录：

```bash
git clone https://github.com/lanyafei8-sketch/yingchao-ai-trends.git
cd yingchao-ai-trends
```

3. 启动本地网页服务：

```bash
node server.js
```

4. 浏览器访问 `http://localhost:4173`。服务默认使用 `4173` 端口；如需更换端口，可在启动前设置 `PORT` 环境变量。

如需生成可部署的静态分享版，执行：

```bash
node build-share.js
```

生成结果位于 `dist` 目录，包含 `index.html`、`styles.css` 和 `app.js`。

## 4. 使用方法

1. 打开首页后，默认看到“全部时间”的历史达标作品；切换到近 48 小时时，没有达标作品会明确显示空榜，不会用旧作品补足数量。
2. 使用平台标签在全部平台、抖音和 B 站之间切换，也可以按作品名或创作者搜索，并使用时间范围筛选。
3. 点击作品所在行可在新标签页打开原视频；点击行末的「详情」可查看公开数据、故事五问、人物分析、幕式结构、核心节拍、观众情绪、可借鉴选题和分镜练习。
4. 点击右上角「导入数据」可以：
   - 上传 UTF-8 编码的 CSV 文件；
   - 连接允许浏览器跨域访问的公开 JSON 地址；
   - 恢复默认公开采样；
   - 切换到每个平台 30 条的演示数据。
5. 导入结果只保存在当前浏览器的 `localStorage` 中，不会修改线上公共榜单或影响其他访客。CSV 文件和 JSON 响应最大为 2 MB，单次及导入后总作品数最多为 500 条；数据会在整批校验通过后一次性保存。
6. 连接 JSON 地址后，页面打开时会读取一次，此后每 5 分钟尝试刷新。
7. 同一作品需要保持相同 `id`。当两次导入都包含有效播放量，且后一次 `observedAt` 晚于前一次时，页面会根据播放量差值计算每小时增长速度。

## 5. 输入输出示例

### CSV 输入示例

CSV 首行是字段名；缺失且无法核实的指标请留空，不要填写 `0`。评论数、时长、高赞评论观点和画面风格均为可选字段。

```csv
id,platform,title,creator,views,likes,comments,shares,duration,commentHighlights,visualStyle,url,publishedAt,observedAt,category
video-001,douyin,我的AI短片,创作者,,108900,3200,1300,00:58,观众关注主角的选择与结尾反转,写实电影感与低饱和冷色调,https://example.com/video/1,2026-09-18T08:00:00+08:00,2026-09-18T12:00:00+08:00,科幻
video-002,bilibili,AI城市漫游,示例UP主,1350000,52000,1800,900,01:26,,,https://example.com/video/2,2026-09-17T20:00:00+08:00,2026-09-18T12:00:00+08:00,城市奇想
```

### JSON 输入示例

JSON 地址可以直接返回数组，也可以返回包含 `videos` 数组的对象。下面两种结构都可以被网页读取：

```json
{
  "videos": [
    {
      "id": "video-001",
      "platform": "douyin",
      "title": "我的AI短片",
      "creator": "创作者",
      "views": null,
      "likes": 108900,
      "comments": 3200,
      "shares": 1300,
      "duration": "00:58",
      "commentHighlights": "观众关注主角的选择与结尾反转",
      "visualStyle": "写实电影感与低饱和冷色调",
      "url": "https://example.com/video/1",
      "publishedAt": "2026-09-18T08:00:00+08:00",
      "observedAt": "2026-09-18T12:00:00+08:00",
      "category": "科幻"
    }
  ]
}
```

### 页面输出示例

导入成功后，网页会重新计算并显示榜单。上面的 `video-001` 会以类似下面的形式出现：

```text
平台：抖音
作品：我的AI短片
创作者：创作者
播放量：—
点赞量：10.9万
评论量：3200
转发量：1300
上涨速度：—（首次采样无法计算）
```

如果随后再次导入相同 `id`，将播放量更新为 `132000`，并把采样时间更新为 `2026-09-18T14:00:00+08:00`，页面会计算：

```text
上涨速度：6000 播放 / 小时
```

页面最多显示当前筛选和排序结果中的前 30 条作品。没有提供的数据会显示为 `—`；导入作品没有内置编辑分析时，详情页会提示尚未完成创作拆解。

## 换成真实数据

点击页面右上角「导入数据」，下载 CSV 模板并导入，或连接一个公开可访问、允许浏览器跨域请求的 JSON 地址。JSON 可以直接是数组，也可以是 `{ "videos": [...] }`。字段：

| 字段 | 说明 |
| --- | --- |
| `id` | 作品稳定 ID；同一作品后续快照须保持一致。缺省时以 URL 或平台、标题、作者组合识别。 |
| `platform` | `douyin` 或 `bilibili` |
| `title`, `creator`, `category` | 作品标题、作者、类别 |
| `views`, `likes`, `comments`, `shares` | 播放、点赞、评论、转发的非负整数；网页未展示时可留空，勿填零 |
| `duration` | 视频时长，例如 `00:58`；无法核实时留空 |
| `commentHighlights`, `visualStyle` | 可选的高赞评论观点摘要与画面风格描述 |
| `url` | 原视频网址，可留空 |
| `publishedAt` | 发布时间，建议 ISO 8601 格式 |
| `observedAt` | 本次采样时间，建议 ISO 8601 格式 |
| `velocity` | 可选，每小时新增播放。若对同一 ID 导入至少两次有效播放量且采样时间递增，页面会按播放差值自动计算。 |

导入的数据保存在当前浏览器 `localStorage` 中。连接 JSON 地址后，打开网页时和此后每 5 分钟会尝试刷新。CSV 模板中的网址和数值仅供说明，不能作为真实榜单数据。

页面先执行平台门槛过滤，再显示当前时间范围内的作品。综合热度只在播放、点赞、转发和上涨速度四项都有有效值时计算，权重为播放 35%、点赞 30%、转发 20%、上涨速度 15%。总榜最多显示 30 名。

## 数据接入限制

本项目不自称接入了两平台的全站实时热搜。抖音官方视频数据接口要求申请权限和视频所属用户授权，其「视频互动数据」能力也限定了使用场景。B 站开放平台提供授权后的稿件数据能力。建立覆盖全平台的真实榜单，需要另行确定有授权的数据源、持续采样方式与部署位置。

- [抖音开放平台：视频数据接入方案](https://open.douyin.com/platform/resource/docs/ability/open-data/video-data-solution)
- [抖音开放平台：查询特定视频的视频数据](https://open.douyin.com/platform/resource/docs/openapi/video-management/douyin/search-video/video-data/)
- [哔哩哔哩开放平台文档](https://open.bilibili.com/doc)
